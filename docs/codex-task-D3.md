## 1. 버그 두 개 (먼저, 작다)

### 1-a. 발톱 넉백이 절대 위치 재설정이라 호랑이가 순간이동한다

`tiger.js` `clawHit()`:
```js
S.tiger.x = S.worldX - CFG.tiger.clawKnockback;   // ← 버그
```
호랑이 위치를 **플레이어 기준 절대값으로 강제**한다. 맞기 직전 거리가 `reach`(195)였다면 순간적으로 130 으로 끌려온다 — 맞으면서 호랑이가 플레이어 쪽으로 딸려오는, 눈에 보이는 순간이동이다.

**고칠 방향**: 넉백은 **플레이어가 뒤로 밀리는 것**이다. 호랑이 위치는 건드리지 말고 `S.worldX` 를 뒤로 민다. 호랑이가 앞에 있는 새 구조(§2)에서는 이게 "맞고 튕겨나 거리가 벌어진다"로 정확히 읽힌다.

### 1-b. 화살 넉백의 방향이 고정돼 있다

`damageTiger()` 의 `T.x -= push` 는 호랑이가 항상 뒤에 있다는 전제다. §2 이후에는 호랑이가 앞에 있을 때 이 식이 호랑이를 **플레이어 쪽으로 당긴다.**
**고칠 방향**: 넉백은 항상 **플레이어에서 멀어지는 방향**이다. 부호를 `gap` 에서 유도하라.

### 1-c. 수그리면 28% 느려진다

`player.js` 의 `if (p.crouch) mul *= K.crouchMul;` — **이 줄을 제거한다.** 회피 동작이 이동을 벌하면 안 된다.
`CFG.player.crouchMul` 은 config 에 남겨두되 쓰지 않는다(주석으로 "사용 안 함" 표시). `aimMul`·`stumbleMul` 은 그대로 둔다.

## 2. 교전 구조 — 추월해서 앞을 막고 뒤돈다

**지금의 문제**: 주석엔 "교전 중에는 좁혀오지 않는다"라고 써 있는데 실제 코드는 `T.x += CFG.player.speedBase * FIXED_DT` 로 **계속 전진한다.** 즉 "멈춘다"는 순간이 코드에도 화면에도 없어서, 공격이 예고 없이 튀어나오는 것처럼 읽힌다.

**바꿀 그림**:
```
①  🦌→   🐯→        뒤에서 추격 (chase)
②  🦌→      🐯→     옆을 지나쳐 추월한다 (overtake)  ← 근접 = 공격 기회
③  🦌→        🐯    앞에서 멈춘다 (brace)            ← 멈춤이 위치로 보인다
④  🦌→       ←🐯    뒤돈다 = 공격 예고 (windup)
⑤  🦌→     ←🐯💥   후려치기 (swing)
```

### 좌표 규약

`gapOf(S) = S.worldX - S.tiger.x` 를 유지한다. **부호가 의미를 갖는다**:
- `gap > 0` → 호랑이가 **뒤**에 있다 (chase)
- `gap < 0` → 호랑이가 **앞**에 있다 (overtake 이후 전부)

거리 판정은 전부 `Math.abs(gap)` 으로 바꿔라.

### 상태 기계

| 상태 | 호랑이 속도 | 전이 조건 |
|---|---|---|
| `chase` | `chaseSpeed` | `gap <= engageGap` → `overtake` |
| `overtake` | `overtakeSpeed` | `gap <= -blockGap` → `brace` |
| `brace` | `overtakeSpeed` → `blockSpeed` 로 감속 (`turnTime` 동안) | 타이머 만료 → `windup` |
| `windup` | **`blockSpeed` 정속** | `windup` 만료 → `swing`. **진입 시점의 플레이어 자세를 거울로 노린다** (기존 규칙 유지) |
| `swing` | 〃 | `abs(gap) <= reach` 이고 노출 → `clawHit` |
| `recover` | 〃 | 취약, 피해 2배 (기존 유지) |
| `cooldown` | 〃 | `abs(gap) > disengageGap` → `chase` / 아니면 → `windup` |

### ⚠ 호랑이는 플레이어 속도를 따라가면 안 된다

앞을 막은 뒤 호랑이가 **플레이어 속도에 맞추면 `A`/`D` 를 눌러도 거리가 영원히 안 변한다.** 반드시 **`blockSpeed` 정속**으로 달려야 한다.

**둘 다 계속 달리고 있다** — "멈춘다"는 건 월드가 아니라 **화면 기준**이다. 호랑이가 정속으로 달리므로 화면에서 제자리에 서 있는 것처럼 보이고, 플레이어의 가감속이 곧 거리 변화가 된다:

| 입력 | 플레이어 속도 | 호랑이 정속 | 거리 변화 |
|---|---|---|---|
| 무입력 | 250 | 250 | 고정 — 화면에서 호랑이가 멈춰 보인다 |
| `A` | 120 | 250 | **초당 130 벌어진다** — 빠르게 떨어진다 |
| `D` | 340 | 250 | 초당 90 붙는다 — 몸통(`bodyGap`)까지 밀어붙일 수 있다 |

`speedBack`(120) 이 크게 잡혀 있는 게 여기서 값어치를 한다 — 뒤로 빼는 게 즉각적으로 느껴져야 "달리면서 거리를 조절한다"가 성립한다.

`chase` 로 돌아갈 때는 호랑이를 뒤로 되돌리지 말고, **플레이어가 지나쳐 가면서 자연히 뒤가 되게** 하라 (호랑이가 감속하면 플레이어가 추월한다). 순간이동은 어디에도 없어야 한다.

### 몸통 차단

호랑이가 앞을 막고 있을 때 플레이어가 통과하면 안 된다.
`abs(gap)` 이 `bodyGap` 아래로 내려가려 하면 `S.worldX` 를 클램프하고 `stumble` 을 건다(`S.events.push({kind:'stumble'})`). **호랑이가 물리적인 벽으로 읽혀야 한다** — 이게 `A`/`D` 에 의미를 준다: `D` = 위험을 무릅쓰고 붙는다, `A` = 물러선다.

### 공격 기회 두 개 (붙을 이유)

1. **`overtake` 구간** — 호랑이가 바로 옆을 스쳐 지나간다. 근접·시간제한 창이다. 이 구간의 피격은 `overtakeDmgMul` 배율을 받는다
2. **`recover` 구간** — 기존 `recoverDmgMul` 2배 유지

### config 에 추가할 값 (시작값 — 튜닝 대상)

```js
overtakeSpeed: 430,     // player.speedFwd(340)보다 커야 전력질주 중에도 추월당한다
blockSpeed: 250,        // 교전 중 호랑이 정속 = player.speedBase. 무입력이면 화면상 정지로 보인다
blockGap: 210,          // 앞에서 자리잡는 거리. reach(195)보다 약간 크게 = 기본적으로 아슬아슬하게 안전
bodyGap: 95,            // 이보다 가까이는 못 간다. 몸통에 막힌다
turnTime: 0.35,         // 감속 + 뒤도는 시간. windup(0.5)과 합쳐 0.85초가 예고 총량
overtakeDmgMul: 1.5,
```
`engageGap`(175) · `disengageGap`(255) · `reach`(195) · `windup`(0.5) 은 **그대로 둔다.**

### 카메라

`view.playerScreenX` 를 **640 → 480 (화면 중앙)** 으로 바꾼다. 호랑이가 앞뒤 양쪽에 서므로 양쪽 여유가 필요하다.

## 3. 벡터 렌더링 — 보이지 않으면 튜닝할 수 없다

`render.js` 는 지금 전부 사각형이라 **달리는지 멈췄는지, 뒤돌았는지, 맞았는지가 안 보인다.** 스프라이트가 아니라 **Canvas2D 벡터 도형**으로 형태를 만든다. 나중에 스프라이트로 갈아끼울 수 있게 그리기 함수를 분리해 둘 것.

우선순위 순:

1. **배경 패럴랙스 3층** — 먼 산(0.15×) / 중간 나무·언덕(0.4×) / 지면 디테일(1.0×). `S.worldX` 로 스크롤. **속도감의 8할이 여기서 나온다**
2. **지면 스크롤 마커** — 풀·돌을 `worldX` 기준으로 배치해 바닥이 흐르는 게 보이게
3. **사슴 + 기수** — 다리 4개를 `S.worldX` 위상으로 교차 애니메이션(속도에 비례한 주기), 기수 실루엣, 활 자세. 수그리면 몸이 낮아지고 다리 주기는 유지
4. **호랑이 자세 3종 + 방향(facing)** — ⓐ달리는 자세(다리 교차 애니메이션 — **교전 중에도 계속 달리고 있다**는 게 보여야 한다. §2 참고: 화면상 정지 ≠ 월드 정지) ⓑ뒤도는 중(`brace`, 몸을 트는 보간) ⓒ앞발 든 후려치기(뒤돈 채 달리며 휘두른다). `gap` 부호로 좌우 반전
5. **스피드라인** — 화면 속도(`p.speed`)에 비례한 가로선. 감속이 눈에 보이게
6. **히트 플래시** — 피격 프레임에 대상을 흰색으로 2프레임 덮기. 가장 싸고 효과가 큰 juice
7. **화면 흔들림 곡선** — 지금 `trauma² × 16` 이라 약한 명중이 **0.52px** 로 사실상 안 보인다. `trauma^1.2 × shakeMax` 로 바꾸고 `shakeMax` 를 24 로 올려라 (약명중이 최소 2~3px 흔들려야 한다)

`render.js` 는 계속 **읽기 전용**이다. 상태를 바꾸지 마라. 애니메이션 위상은 `S.worldX`·`S.t` 에서 유도하라(별도 상태를 만들지 말 것 — 결정론이 깨진다).

**소리는 이번 작업에 넣지 마라.** 다음 작업으로 따로 뺀다.

```bash
node --test tests/determinism.test.mjs   # 3/3 유지

```
그리고 `dist/play.html` 을 열어 **눈으로** 확인:
- 호랑이가 옆을 지나쳐 앞으로 가고, 멈추고, 뒤도는 게 **위치와 자세로** 보인다
- 발톱에 맞았을 때 호랑이가 순간이동하지 않는다
- 수그려도 느려지지 않는다
