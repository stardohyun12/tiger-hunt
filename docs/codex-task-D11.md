## 1. 터치 조작을 좌우로 나눈다 (도현 지시)

지금은 4버튼이 **우하단에 2×2 뭉치**다. 도현: **"앞뒤, 점프 숙이기 왼쪽 오른쪽으로 나눠줘"**

```
┌────────────────────────────────────────────┐
│                                            │
│         ← 조준 영역 (가운데 전체) →         │
│                                     [점프]  │
│  [뒤][앞]                          [수그림] │
└────────────────────────────────────────────┘
```

- **좌하단 = 앞뒤, 가로 쌍**: `뒤` 중심 (78, 478) · `앞` 중심 (188, 478) · r 48
  왼쪽 버튼이 뒤, 오른쪽 버튼이 앞 — **배치가 곧 의미다**
- **우하단 = 점프/수그리기, 세로 쌍**: `점프` 중심 (884, 368) · `수그림` 중심 (884, 478) · r 48
  위 버튼이 점프, 아래 버튼이 수그리기 — **배치가 곧 의미다**
- 나머지 전부가 조준 영역. 멀티터치 역할 분배(D5)는 그대로

### 겹침 검증 — 계산으로 확인하라
조준을 버튼이 잡아먹으면 안 된다. 실제 호랑이 위치는:
- **후방 교전**(standoff 115): 화면 x = 480 − 115 = **365**, 스프라이트 폭 120 → **305~425**
- **전방 교전**(bodyGap 95 ~ blockGap 210): 화면 x **575~690**, 스프라이트 폭 포함 **515~750**

좌측 패드는 x ≤ 236, 우측 패드는 x ≥ 836 이므로 둘 다 뚫린다. **이 여백을 확인하고,
값을 바꾸게 되면 다시 계산해서 로그에 적어라.** 지금 배치(우하단 2×2)보다 조준이 넓어져야 한다.

### 타이틀 조작법 문구도 갱신
터치 모드 문구를 새 배치에 맞춰라 (대회 필수 요건이라 화면에 상시 보여야 한다):
```
좌하단 뒤·앞 · 우하단 점프·수그리기
가운데를 눌러 조준 → 홀드 차지 → 떼면 발사
```

## 2. 산이 밋밋하다 (도현 지시)

D10 으로 빌딩은 없어졌지만 결과가 약하다. 실제 화면에서 본 문제 셋:

1. **능선이 낮다.** 최고점이 화면 높이의 20% 남짓이라 산이 아니라 언덕이다.
   **화면 위 절반이 통째로 빈 한지다**
2. **중간 층이 능선이 아니라 납작한 띠**로 읽힌다. 실루엣 형태가 거의 없다
3. **먼 층과 중간 층의 명도 차가 작아** 두 겹이 안 갈린다

### 고칠 것
- **봉우리를 키워라.** 능선 최고점이 **화면 높이의 40% 이상**(216 뷰단위 이상) 올라오게.
  높이를 균일하게 올리지 말고 **높은 봉우리 몇 개 + 낮은 것 여럿**으로 리듬을 만들어라.
  한국 산은 나란한 삼각형이 아니라 **주봉 하나에 능선이 흘러내리는** 형태다
- **중간 층에 형태를 줘라.** 지금은 띠다. 봉우리 수를 늘리고 `spread` 를 줄여
  능선이 오르내리는 게 보이게 하라
- **명도 차를 벌려라.** `C.inkFar` / `C.inkMid` 알파 차이를 지금보다 크게.
  다만 **먹 알파 두 단계 규율은 유지** — 세 번째 회색을 만들지 마라
- 인접 열 높이차 상한(3칸)은 계속 지켜라. 넘으면 다시 벽면이 된다

## 3. `tigerBrace` 가 아직 덩어리다 (도현 지시)

D9 에서 `tigerWindup`/`tigerSwing` 은 고쳤지만 `tigerBrace`(뒤도는 자세)는 그대로다.
**같은 기준을 적용하라**: 채움 비율 ≤ 55%, 다리 분리, 목 잘록함, 꼬리 구분.
뒤도는 중간 자세이므로 몸이 좁아 보이되 **네 다리가 엇갈린 형태**로 회전 중임이 읽혀야 한다.
`tigerRunA`(54.9%)가 기준이다. 판정판에 채움 비율을 찍어라.

## 4. 사슴+기수 (도현 지시)

실제 화면에서 보면 **활을 들고 있는 게 거의 안 보인다.** 기마궁술 게임인데 활이 안 보인다.
- 기수의 상체를 조금 키우고, **활을 든 팔의 형태가 실루엣에서 읽히게** 하라
- `drawBow` 의 활대 선 두께(`A.bow.lineW`)를 키워라. 지금은 얇아서 배경에 묻힌다
- 조준 중이 아닐 때도 활이 보여야 한다 — 이 캐릭터의 정체성이다
- ⚠ `bowScreen()` 은 `arrow.js`(sim) 라 **손대지 마라.** 활의 위치는 그대로 두고 **그리는 방식만** 바꾼다
