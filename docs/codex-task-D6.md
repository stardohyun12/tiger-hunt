# Codex 작업 지시 — D6: 다리 리깅 (사슴·호랑이·기수)

**먼저 `AGENTS.md` 를 읽어라.** 매 단계 `node --test tests/determinism.test.mjs` 유지.

도현 판정: **"다리 부분이 너무 짜친다."** 취향 문제가 아니라 구조적 결함 4건이다. 아래 진단은 실측이다.

**`render.js` 와 `config.js` 만 고친다.** `sim.js`·`player.js`·`tiger.js`·`arrow.js`·`obstacle.js`·
`rng.js`·`replay.js`·`state.js` **수정 금지** — 특히 `arrow.js` 의 `bowScreen()` 은 화살 발사 지점이라

`render.js` 는 결정론 스캔 대상이 아니다 → **`Math.sin`/`cos`/`atan2` 를 써도 된다.**
반대로 `config.js` 는 스캔 대상이니 **숫자만** 넣어라 (`Math.*` 호출 금지).

## 1. 진단 (전부 현재 코드에서 계산한 값이다)

### 1-a. 다리가 몸통에 파묻혀서 22px 밖에 안 보인다 — 가장 큰 원인
- 사슴 몸통: `ellipse(0, ground-46, 43, 22)` → 아랫배 `ground-24`. 발굽 `ground-2`.
  **보이는 다리 = 22px**, 플레이어 키 96px 의 23%. 실제 사슴/말은 서 있는 높이의 **약 50%** 가 다리다
- 호랑이 몸통: `ellipse(0, -48, 53, 25)` → 아랫배 `-23`. 발 `-2`. **보이는 다리 = 21px**, 키 74px
- ⇒ 다리가 아니라 **몸통에 달린 짧은 돌기**로 읽힌다. 애니메이션을 아무리 고쳐도 이걸 안 고치면 안 산다

### 1-b. 다리 길이가 보존되지 않는다 (고무줄)
`drawDeerLeg`: 엉덩이 `(x, ground-42)` · 무릎 `(x+13p, ground-21)` · 발굽 `(x-16p, ground-2)`
- 정강이 = `sqrt((29p)² + 19²)` → `p=0` 에서 **19px**, `|p|=1` 에서 **34.7px**. **82% 신축**
- 허벅지 = `sqrt((13p)² + 21²)` → 21 ~ 24.9px (19% 신축)
- 뼈는 늘어나지 않는다. 이게 "짜친" 느낌의 직접적 원인이다

### 1-c. 발이 땅에서 안 떨어진다
발굽 y 가 **항상 `ground-2` 고정**. 들어올리는 동작이 없어서 바닥을 좌우로 쓸기만 한다.

### 1-d. 무릎 꺾임 방향이 반주기마다 뒤집힌다
`p>0` → 무릎 앞·발 뒤 (Z 자) / `p<0` → 무릎 뒤·발 앞 (역 Z). 곧은 상태를 관통하며 뒤집힌다.
관절은 한 방향으로만 꺾인다.

### 1-e. 호랑이 발이 미끄러진다
사슴 보폭은 `Math.sin(S.worldX * 0.075)` — **거리 기반**이라 속도가 변해도 안 미끄러진다. 좋은 판단이다.
호랑이는 `Math.sin(S.t * CFG.tiger.blockSpeed * 0.06)` — **시간 기반 + 고정 속도**라
실제 속도(chase 245 · overtake 430 · block 250 · 전방 chase 175)와 어긋나 발이 지면을 긁는다.

## 2. 고칠 것

### 2-a. 몸통을 올리고 다리 공간을 확보하라 (먼저)
목표: **보이는 다리 길이를 사슴 34~38px, 호랑이 30~34px 로.** 방법은 둘을 섞어라 —
몸통 중심을 올리고, 세로 반지름을 약간 줄인다 (사슴 22→19, 호랑이 25→22 정도가 출발점).

⚠ **몸통만 올리면 머리·뿔·꼬리·기수가 공중에 뜬다.** 같은 델타를 실루엣 전체에 일관되게 적용하라:
사슴의 머리·목·뿔·꼬리 좌표, `drawRider` 의 `hipY`/`shoulderY`/`headY`(서기·수그리기 양쪽),
호랑이의 머리·귀·꼬리·줄무늬 y. **`bowScreen()` 은 못 바꾸므로** 기수 손 위치는 그대로 두고
몸/머리만 올린 뒤, 활을 든 팔이 어색하지 않은지 캡처로 확인해 보정하라.

수치는 `config.js` 에 `rig` 같은 이름으로 모아라 (다른 파일에 하드코딩 금지 — AGENTS.md).

### 2-b. 2본 IK 로 다리 길이를 보존하라
허벅지 `L1`, 정강이 `L2` 를 **상수로 고정**하고, 엉덩이와 발 위치가 주어지면 무릎을 계산한다.

```
d = 엉덩이→발 거리 (L1+L2 로 클램프, 0 나눗셈 방지)
a = (d² + L1² - L2²) / (2d)           // 엉덩이에서 무릎 투영까지
h = sqrt(max(0, L1² - a²))            // 다리 축에서 무릎까지의 수직 거리
무릎 = 엉덩이 + 단위벡터(엉덩이→발)*a + 수직단위벡터 * h * bendSign
```
`bendSign` 은 **다리마다 상수**다. 절대 부호가 바뀌면 안 된다 (1-d 재발).
- 앞다리(사슴·호랑이): 무릎이 **뒤로** 꺾인다 → 진행 반대 방향
- 뒷다리: 비절(hock)이 **뒤로** 크게 꺾인다 → 뒷다리 특유의 Z 실루엣.
  뒷다리는 `L1` 을 앞다리보다 길게 잡으면 이 형태가 자연히 나온다

### 2-c. 발이 미끄러지지 않는 보행 주기 (stance/swing 분리)
보행 위상은 **거리**에서 나온다. `u = ((worldX / strideLen) + legOffset) mod 1`.

```
duty = 0.6   // 접지 비율
u < duty  (stance, 접지):
    발은 월드에 박혀 있다 → 몸 기준으로 뒤로 등속 이동
    footX = x + strideX/2 - strideLen * u
    footY = 0                                  // 지면
u >= duty (swing, 유각):
    s = (u - duty) / (1 - duty)
    footX = x - strideX/2 + strideX * s        // 뒤에서 앞으로
    footY = -liftMax * Math.sin(Math.PI * s)   // 들어올렸다 내려놓는 아치
strideX = strideLen * duty
```
이 식이면 **접지 중 발의 월드 좌표가 고정**된다 = 미끄러짐 0. `liftMax` 는 사슴 16 · 호랑이 13 정도에서 시작.

다리별 `legOffset`: 사슴은 대각선 쌍(트롯)을 유지하라 — 현재 `(-30, 32)` 와 `(-13, 16)` 이 각각 대각쌍이고
이 짝은 **맞다**. 오프셋 `0, 0.5, 0.5, 0` 으로 주면 지금 위상 관계가 보존된다.
호랑이는 포식자 갤럽이 어울린다 — 앞다리 둘을 거의 같은 위상(0, 0.1), 뒷다리 둘을 반대(0.5, 0.6)로.

### 2-d. 호랑이 보폭도 거리 기반으로
`S.t * CFG.tiger.blockSpeed` 를 **`S.tiger.x`(월드 좌표)** 로 바꿔라. 속도가 뭐든 발이 안 긁힌다.
호랑이가 뒤로 밀릴 때(화살 넉백) 보폭이 역행하는 것도 자연스럽다.

### 2-e. 접지감 (여기까지 하면 확 산다)
- **그림자**: 두 동물 발밑에 `C.ink` alpha 0.22 타원. 사슴은 점프 높이(`p.y`)에 따라
  **작아지고 옅어져야** 한다 — 점프 높이를 읽는 유일한 단서다
- **먼지**: 발이 stance 로 진입하는 순간(`u` 가 0 을 지날 때) 작은 흙먼지 몇 점.
  난수 대신 `worldX` 에서 유도해 프레임마다 튀지 않게 하라

### 2-f. 기수 다리
`drawRider` 의 다리는 엉덩이에서 `(12, ground-43)` 로 가는 **직선 하나**다 — 무릎도 발도 없다.
등자를 밟은 다리로 만들어라: 엉덩이 → 무릎(앞으로) → 발(등자, 사슴 몸통 옆). 사슴 상하 반동에
살짝 따라 움직이면 좋다. 수그리기 자세에서도 자연스러워야 한다.
