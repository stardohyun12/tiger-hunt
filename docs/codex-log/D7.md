- 받은 것: `docs/codex-task-D7.md`에 따라 후방 공격 완주·속도 기반 추월·방향별 발톱 넉백·앞선 호랑이 복귀를 구현하고, 밸런스 프로브·결정론·빌드·실제 캔버스를 검증하라는 지시.
- 구현한 것: `src/config.js`·`src/tiger.js`에 후방 standoff, 전후방 넉백 분기, 후방에서만의 속도 기반 추월, 플레이어 속도 비율 전방 추격, chase 접촉 선판정과 D 가속분 추격 보정을 구현했고, 후방 연타 간격 12초를 추가해 무입력 사망 38.7초로 맞춤; `tools/balance-probe.mjs`에는 최대 `|gap|`·호랑이 프레임 이동·`gapMax` 연속 프레임을 추가했으며 `D7-rear-windup.png`로 후방 텔레그래프와 앞발 방향을 검증함.
- 막힌 곳: 지시값만 적용하면 무입력이 15.3초에 3연타로 사망하고 D 홀드는 교전 0회라 합격 기준과 충돌했으나, 전방 주기는 유지한 별도 후방 cooldown과 기본 속도 초과분만 반영하는 추격으로 해결함; 앱 내 브라우저 연결은 세 차례 시간 초과되어 저장소 D4~D6와 같은 설치형 Edge 헤드리스 캡처로 대체함.
- 사람이 정한 것: 후방 교전 중 standoff 클램프로 공격을 끝까지 보장하고, 추월을 `player.speed < tiger.chaseSpeed`로 판정해 조준 중 추월당하는 것이 “쏘는 데 거리를 낸다”는 설계와 맞도록 하며, 후방 넉백은 앞으로 밀되 stumble로 순손실을 만들고, 앞선 호랑이 속도는 플레이어 속도 비율로 정함.
