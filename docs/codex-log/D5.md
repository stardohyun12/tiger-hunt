- 받은 것: `docs/codex-task-D5.md`에 따라 sim 계층은 수정하지 않고, 정수 입력 계약을 유지한 채 모바일 Pointer Events·멀티터치·우하단 패드·터치 조작 안내·세로 모드 안내를 구현하고 실제 Edge에서 검증하라는 지시.
- 구현한 것: `src/config.js`에 터치 기하·표시값과 4패드를 모으고, `src/input.js`에 문서 단위 포인터 역할 고정·패드 재바인딩·좌표 클램프·취소/숨김/블러 해제·터치 모드 감지를 추가했으며, `src/render.js`에 눌림 피드백·터치 조작표·조준 표적을, `index.html`에 모바일 viewport/CSS와 CSS 전용 세로 안내를 구현함; 금지된 sim 파일은 변경하지 않음.
- 막힌 곳: 내장 브라우저 연결과 진단 호출이 반복 시간 초과되어 D4와 같은 설치형 Edge 헤드리스/CDP로 전환함; 실제 터치 입력 비트 4종, 이동+조준 동시 입력, 조준 포인터의 패드 위 드래그 유지, `pointercancel` 뒤 `S.aiming === false`, 세로/가로 안내 전환, 마우스 회귀, 런타임 예외 0건을 확인하고 터치 리플레이의 Node 재생 해시도 일치시킴.
- 사람이 정한 것: 패드는 우하단에 둔다—조준 방향이 활에서 터치 지점으로 나가므로 호랑이가 있는 좌측·중앙을 조준 영역으로 비워야 한다; 조준점의 손가락 위 오프셋은 방향 감각을 비선형으로 바꾸므로 쓰지 않는다; 세로 모드는 게임을 억지로 축소하지 않고 CSS 안내 오버레이로 처리한다.
