## 1. D3 검산에서 나온 버그 2건 (먼저)

### 1-a. 무입력 플레이어가 영원히 안 맞는다
brace 종료 시 정지 거리가 약 -246 인데 `reach` 가 195 라 swing 이 항상 헛스윙이다.
**"가만히 있으면 100% 맞는다"가 이 게임의 명제다** (HANDOFF 참조). 고칠 방향:
- `windup` 동안 호랑이가 플레이어 쪽으로 서서히 다가온다 (`blockSpeed` 에 접근 속도를 더해 `abs(gap)` 이 `reach` 안으로 들어오게). windup 0.5초 안에 -246 → ≤190 까지 오려면 접근 속도 ≈ +115/s. `config.js` 에 `approachSpeed` 로 추가
- 뒤돌고 → **다가오며** → 후려친다. 시각적으로도 위협이 커지는 그림이라 텔레그래프가 강해진다
- `A` 로 물러나면 여전히 피할 수 있어야 한다: `speedBack`(120) 기준 이탈 속도가 접근 속도보다 크므로 성립함을 확인하라

### 1-b. 앞에 있는 호랑이가 도망간다
플레이어가 장애물에 걸려 느려지면 전방의 chase 호랑이가 격차를 계속 벌린다 (실측 -1293px).
**chase 상태에서 `gap < 0`(호랑이가 앞)이면 감속해서 플레이어가 자연히 추월하게 하라** (예: `blockSpeed * 0.7`). 플레이어가 지나쳐 `gap > 0` 이 되면 정상 chase 로 복귀. 순간이동 금지.

## 2. 게임 UI — 화면 3장

지금은 타이틀도 게임오버도 텍스트 한 줄이다. **전부 `render.js` 안의 벡터 드로잉**으로 만든다 (이미지 파일 금지 — 스프라이트는 나중에 갈아끼운다). 민화 톤 팔레트를 쓰라: 한지 미색 `#E8DCC0`, 먹 `#2B2320`, 황토 `#C8862A`, 주홍 `#B03A2E` (`config.js` 의 `C` 에 추가).

### 2-a. 타이틀 화면 (`phase: 'title'`)
- 게임 제목: **《호랑이 추격》** (부제: 활 하나로 호랑이를 따돌려라)
- **조작법 표 전체가 항상 보여야 한다** — 대회 필수 요건이다:
  `W 점프 · S 수그리기 · A/D 거리 조절 · 마우스 조준 · 좌클릭 홀드→놓기 발사 · Space 시작`
- 핵심 규칙 한 줄: "빨간 예고가 뜨면 0.5초 — 서 있으면 위를, 수그리면 아래를 노린다"
- 배경에 게임 장면이 어둡게 계속 돌고 있으면 좋다 (데모 어트랙트) — 단, **타이틀 데모는 sim 을 돌리되 입력 0 고정**으로, 리플레이 기록은 하지 않는다

### 2-b. 게임 중 HUD 재정리
- 좌상단: 체력 (하트 3개 벡터로 — 숫자 금지)
- 우상단: 점수 (크게) + 처치 수
- 점수 체계를 sim 에 추가: **생존 거리 1점/10px + 명중 25점 + 강명중 60점 + 처치 500점**. `config.js` 에 `score` 블록으로. `S.score` 는 이미 있으면 활용, 없으면 추가 (정수만)
- 하단 중앙: 차지 게이지 (당기는 동안만 표시)

### 2-c. 게임오버 화면 (`phase: 'over'`)
- "쓰러졌다" + 최종 점수(크게) + 처치 수 + 달린 거리
- **최고 기록**: `localStorage` 에 저장·표시 — 단 **`main.js` 에서만** 접근한다 (sim·replay 는 localStorage 금지, 정적 스캔에 걸린다). 갱신 시 "신기록!" 강조
- "Space — 다시 도전" 안내
