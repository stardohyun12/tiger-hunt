# Codex 작업 지시 — D14: 소리 — WebAudio 코드 합성 (에셋 파일 0개)

**먼저 `AGENTS.md` 를 읽어라.** 이번 작업은 **sim 을 건드리지 않는다.**
`src/` 의 sim 파일(`config.js` 제외)을 수정해야 할 것 같으면 그건 설계가 틀린 것이다 — 멈추고 로그에 적어라.

---

## 0. 왜 이걸 하는가

**지금 이 게임에는 소리가 하나도 없다.** 오디오 파일도, 코드도 없다.
심사에서 체감 대비 비용이 가장 큰 구멍이고, 하루 안에 닫힌다.

에셋을 만들지 않는다 — **전부 WebAudio 코드 합성이다.** 새 파일은 `src/audio.js` 하나,
추가되는 바이너리는 **0개**. `dist/play.html` 단일 파일 크기도 몇 KB만 는다.

`S.events` 가 이미 이벤트 버스로 돌고 있다 (`sim.js` 가 매 프레임 채우고 `main.js` 가 fx 로 소비한다).
**같은 버스를 오디오가 한 번 더 구독하면 끝난다.**

## 1. 설계표 — `docs/design/night-research.md` §3 에 이미 있다

| 소리 | 합성 레시피 | 트리거 |
|---|---|---|
| 시위 당김 | 노이즈 + 로우패스 스윕 200→800Hz, **차지에 비례** | `c===1` 이후 홀드 중 |
| 발사 | 80ms 노이즈 버스트 + 220Hz 사인 감쇠 | `c===2` (발사 성공 시에만) |
| 약명중 | 440Hz 삼각파 60ms | `hitWeak` |
| 강명중 | 110Hz 사각파 + 노이즈 120ms (북) | `hitStrong` |
| 발톱 피격 | 화이트노이즈 하이패스 찢는 소리 180ms | `claw` |
| 처치 | 55Hz 사인 300ms + 880Hz 벨 (북+공) | `kill` |
| 착지/비틀 | 90Hz 60ms 퍽 | `stumble` |

**이 표는 출발점이지 성경이 아니다.** 귀로 확인할 수 없는 환경이라면 표대로 구현하고,
수치는 전부 `CFG.audio` 에 빼서 사람이 나중에 돌릴 수 있게 하라.

### D12·D13 이후 늘어난 이벤트 — 표에 없는 것들
`sim.js` 가 실제로 뿜는 이벤트 목록을 **코드에서 직접 확인해서** 빠짐없이 다뤄라.
최소한 아래는 소리가 있어야 한다:

- **`tigerEnter`** (호랑이 난입) — 이 게임에서 **가장 중요한 순간**이다. 낮은 포효 + 북 한 방.
  1.5초 경고 연출과 붙어야 한다. 다른 어떤 소리보다 크고 낮게
- **과녁 명중** — D12 에서 들어온 주 수입원이다. 맑고 짧은 타격음(나무에 박히는 소리).
  **콤보 배수가 오를수록 음정을 반음씩 올려라.** 이게 "한 발 더"를 만드는 값싼 장치다
- **과녁 놓침 / 콤보 끊김** — 짧고 건조한 소리. 벌이 아니라 정보다. 작게
- **재장전 완료**(D13 `nockTime` 종료) — 아주 작은 딸깍. **다시 쏠 수 있다는 신호**다.
  D13 에서 활에 재장전 대기를 넣었으므로 이게 없으면 언제 쏠 수 있는지 손이 모른다

이벤트 이름을 추측하지 마라. `grep -n "S.events.push" src/` 로 실제 목록을 뽑고 그걸 기준으로 짜라.

## 2. 구조

**새 파일 `src/audio.js`** (presentation 계층):

```
initAudio()          최초 1회. AudioContext 생성은 사용자 제스처 뒤로 미룬다
resumeAudio()        첫 입력에서 호출 (iOS/Chrome 자동재생 정책)
playEvents(events)   S.events 배열을 받아 소리를 친다
updateAudio(S)       홀드 중인 지속음(시위 당김)의 파라미터를 매 프레임 갱신
setMuted(on) / isMuted()
```

- `main.js` 가 **fx 를 치는 바로 그 자리**에서 `playEvents(S.events)` 를 부른다.
  이벤트 소비 지점을 두 군데로 늘리지 말고 같은 루프 안에 둬라
- ⚠ **`audio.js` 는 `S` 를 절대 수정하지 않는다.** `render.js` 와 같은 읽기 전용 규율이다
- ⚠ **sim 은 오디오를 모른다.** `sim.js`/`tiger.js`/`arrow.js` 에서 오디오 함수를 부르지 마라
- 노드 생성은 소리마다 새로 만들고 끝나면 `stop()` 으로 정리하라 (누수 금지).
  `GainNode` 하나를 마스터로 두고 전부 거기로 모아라

### 결정론
오디오는 presentation 이라 `Math.random()` 을 써도 결정론이 안 깨진다
(`AGENTS.md` §1-(3) 의 `fx.js` 예외와 같은 논리). **단 `S` 를 건드리지 않는 한에서만이다.**
화이트노이즈 버퍼는 `Math.random()` 으로 만들어도 된다 — **한 번 만들어 재사용하라.**
매 발사마다 버퍼를 새로 채우면 GC 가 튄다.

`tests/determinism.test.mjs` 의 정적 스캔 대상에 `audio.js` 가 들어가면 안 된다.
스캔 목록이 sim 파일만 훑는지 확인하고, 아니라면 **테스트의 스캔 목록에서 audio.js 를 제외하라**
(스캔 자체를 약화시키지 마라 — 목록에서 빼는 것과 검사를 지우는 건 다르다).

## 3. 음소거 · 첫 재생

- **`M` 키로 음소거 토글.** 상태를 `localStorage` 에 저장해 다음 판에도 유지
- 화면에 음소거 상태를 작게 표시하라 (HUD 구석. 조작법 표기에 `M 음소거` 추가)
- ⚠ **자동재생 정책**: `AudioContext` 는 사용자 제스처 전에는 `suspended` 다.
  첫 키/터치/클릭에서 `resume()` 하라. 그 전에는 조용히 아무것도 하지 않는다 (콘솔 에러 금지)
- ⚠ **타이틀 데모가 소리를 내면 안 된다.** `main.js` 의 `updateTitleDemo()` 가 sim 을 돌리고 있어서
  그대로 두면 **타이틀 화면에서 혼자 소리가 난다.** `phase === 'play'` 일 때만 이벤트를 소리로 바꿔라
- 페이지가 숨겨지면(`visibilitychange`) 마스터 게인을 0 으로. 탭 전환하고 소리가 계속 나면 안 된다

## 4. 믹싱 — 이게 없으면 시끄럽기만 하다

- **동시 발생 상한**: 같은 프레임에 같은 소리가 여러 번 들어오면 **한 번만** 친다.
  화살이 여러 발 동시에 맞을 때 진폭이 겹쳐 찢어지는 걸 막는다
- **우선순위**: `claw` · `tigerEnter` 는 다른 소리를 눌러야 한다. 마스터 게인을 잠깐 덕킹하거나
  다른 채널을 줄여라
- 전체 볼륨은 **작게** 시작하라. 심사자가 이어폰을 끼고 있을 수 있다.
  마스터 기본값을 0.35 정도에 두고 `CFG.audio.master` 로 뺴라
- 모든 수치(주파수·길이·게인·디튠)는 **`config.js` 의 `CFG.audio` 에만.**
  `audio.js` 안에 상수를 새로 만들지 마라 (`AGENTS.md` §3)

## 5. BGM 은 만들지 마라

후순위로 합의된 항목이다. 시간이 남으면 **아주 낮은 지속음(드론) 하나**로 긴장만 깔되,
호랑이 난입 이후에만 켜라. 멜로디를 작곡하려 들지 마라 — 코드 합성으로 만든 멜로디는
싸구려로 들리고 시간을 잡아먹는다.

## 6. 검증

1. **결정론 3/3 유지** (`node --test tests/determinism.test.mjs`) · `node build.mjs` 성공
2. **`dist/play.html` 크기를 보고하라.** 오디오 추가 전후 바이트 수를 둘 다 적어라
3. `node tools/balance-probe.mjs` 가 여전히 돈다 (오디오는 Node 에 없는 API 다 —
   **sim 만 import 하는 probe 가 audio.js 를 끌어오면 즉시 터진다.** 이게 계층 위반 탐지기다)
4. 헤드리스에서 소리를 들을 수 없다는 점을 인정하고, 대신 **콘솔 로그로 검증**하라:
   각 이벤트에서 어떤 소리가 몇 Hz·몇 ms 로 스케줄됐는지 찍는 임시 로그를 넣고,
   한 판을 돌려 **모든 이벤트 종류가 최소 한 번씩 발화하는지** 확인한 뒤 로그를 제거하라
5. 캡처는 생략한다 (소리는 눈으로 못 본다). 도현이 직접 듣고 판정한다
