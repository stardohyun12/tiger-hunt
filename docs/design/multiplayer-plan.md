# 멀티 계획 — 결정 (2026-08-20 도현 승인)

> 도현: "멀티로써 조금 아쉬운 것 같은데 추후 컨텐츠로 조금 더 놓을 수 있으려나"
> 판정: **고스트 + 서버 검증 랭킹까지 마감 전. 실시간 1v1 은 마감 후 컨텐츠.**
> **wrangler devDependency 승인됨** (AGENTS.md 의존성 정책상 필요했던 승인).

## 왜 이 범위인가

"멀티가 아쉽다"의 원인은 대전이 없어서가 아니라 **화면에 다른 사람의 존재가 없어서**다.
매일 같은 시드(`main.js` 의 `dailySeed()`)라 전원이 **같은 판**을 푼다 ⇒ 고스트가 곧 직접 대결이고,
비동기인데도 붙는 느낌이 난다. 이게 가장 싼 값에 가장 큰 체감을 준다.

실시간 1v1 을 미루는 건 기능을 포기하는 게 아니다. 1·2·3 이 돌고 있으면 결정론 기반이
**이미 증명된 상태**라 4번은 로드맵이 아니라 명백한 다음 단계로 읽힌다.

## 이미 확보된 기반 (새로 만들 것이 아니다)

| 있는 것 | 어디 |
|---|---|
| 같은 시드+입력열 → 같은 상태 해시 (시드 100개 검증) | `tests/determinism.test.mjs` |
| 입력 델타 기록·직렬화·왕복 재생 | `replay.js` — `record` / `serialize` / `deserialize` / `playback` |
| gameplay 전용 상태 해시 (presentation 값 제외) | `replay.js` `hashState()` |
| sim 이 브라우저 API 없이 Node 에서 그대로 돈다 | 테스트가 Node 에서 직접 돌린다 |
| 터치로 만든 입력열도 재생 일치 | D5 Codex 검증 |
| 매일 같은 코스 | `main.js` `dailySeed()` |
| 빈 `worker/` 폴더 | 처음부터 이 목적으로 비워둔 자리 |

`replay.js` 헤더에 이미 적혀 있다: **"브라우저 main과 서버 검증기가 같은 입력 스트림을 재생한다."**
서버 검증기는 입력열을 받아 `playback()` 을 돌리고 점수를 비교하는 것이 전부다.

## 사다리

### 1. 자기 최고기록 고스트 (서버 0)
최고 점수 런의 `replay` 를 `localStorage` 에 저장. 다음 판에서 같은 시드로 `playback` 을
프레임 단위로 병행 진행시켜 **반투명 사슴**을 같은 화면에 렌더.
- ⚠ 고스트 sim 을 **본 게임 sim 과 섞지 마라.** 별도 `S_ghost` 를 돌리고 렌더만 겹친다
- ⚠ 고스트는 `S.events` 를 발생시키면 안 된다 (SFX·화면 흔들림이 두 배로 터진다)
- 표시는 위치만: 사슴 실루엣 + 점수. 화살·호랑이는 그리지 않는다 (화면이 죽는다)

### 2. 서버 검증 랭킹 (Cloudflare Workers)
클라이언트가 `{seed, frames, inputs, claimedScore}` 를 제출 → Worker 가 `playback()` 으로
**재계산**해서 `S.score` 와 `claimedScore` 가 일치할 때만 등재.
- Workers 도 V8 이라 결과 비트가 같다 (AGENTS.md 의 float 허용 근거와 같은 논리)
- 저장은 KV 또는 D1. 시드별(=날짜별) 상위 N
- ⚠ **입력열 크기**: 조준 좌표가 매 프레임 바뀌어 60초당 20~30KB. gzip 으로 몇 KB 지만,
  제출 경로에는 `ax`/`ay` 양자화를 한 단계 더 거는 것을 검토 (결정론이 깨지니
  **sim 입력 자체를 바꾸는 것이 아니라, 입력 생성 단계에서 격자에 맞추는 방식**이어야 한다)
- ⚠ 프레임 수 상한을 둬서 무한 페이로드를 막을 것
- ⚠ 정적 자산은 Workers assets 바인딩으로. **GitHub Pages 배포는 그대로 유지한다**
  (Workers 가 망가져도 제출 링크가 살아 있어야 한다 — 이게 이중화의 요점)

### 3. 오늘의 1위 고스트
1+2 위에 얹는다. 1위 입력열을 내려받아 1번과 같은 방식으로 병행 재생.
**멀티 체감의 대부분이 여기서 나온다.**

### 4. 실시간 1v1 — 마감 후
Durable Object 룸 + 락스텝 입력 교환. 지연 처리·룸 동기화에 2~3일.
남은 6일에 아트 전면 개편·SFX·썸네일이 겹쳐 있어 **일정을 깰 수 있는 유일한 항목**이라 미룬다.
